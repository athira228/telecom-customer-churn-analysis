# Telecom Customer Churn Analysis

## Overview

This project analyzes customer churn in a telecom company using SQL Server and Power BI. The goal was to understand why customers leave, identify high-risk customer groups, measure the impact of churn on revenue, and provide insights to support customer retention.

## Tools Used
* SQL Server
* Power BI
* DAX

## Key Questions
* Why are customers leaving?
* Which customers are most likely to churn?
* How does churn vary by contract type, tenure, and payment method?
* What is the impact of churn on revenue?

## Key Findings
* Customers on month-to-month contracts had the highest churn rate.
* Customers with less than one year of tenure were more likely to leave.
* Electronic check users showed higher churn levels.
* Fiber optic customers experienced higher churn rates than DSL customers.
* Customer churn resulted in significant revenue loss.
